# Romulo - Plugin Pag Mentoria

Plugin WordPress para criar timelines interativas e responsivas com vídeos do YouTube.

## Como Usar

1. Instale o plugin no seu WordPress.
2. Use o shortcode `[timeline]` em qualquer página ou post.
3. Se você estiver logado como administrador, verá um ícone de lápis no canto inferior direito.
4. Clique no ícone para abrir o editor e gerenciar os passos da sua timeline.

## Funcionalidades

- Shortcode `[timeline]` fácil de usar.
- Design Premium (Dark Mode com acentos Laranja).
- Editor visual via popup para administradores.
- Responsivo para Celular, Tablet e Desktop.
- Suporte a vídeos do YouTube.
